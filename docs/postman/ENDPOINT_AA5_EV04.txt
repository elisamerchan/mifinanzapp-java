ENDPOINTS DE LA API - Mi FinanzApp (GA7-220501096-AA5-EV04)
Aprendiz: Elisa Nohemi Merchan Carrillo
Repositorio: https://github.com/elisamerchan/mifinanzapp-java

URL base (local): http://localhost:8080
Formato: JSON (Content-Type: application/json)
Documentacion interactiva (Swagger): http://localhost:8080/swagger-ui.html
Especificacion OpenAPI:              http://localhost:8080/v3/api-docs

Autenticacion: /api/auth/** es publico. Todos los demas endpoints exigen HTTP Basic
(usuario = email y contrasena con los que se registro la cuenta). Sin credenciales: 401.

------------------------------------------------------------
AUTENTICACION (publico)
------------------------------------------------------------
POST   /api/auth/registro            Registra un usuario            201 / 400 / 409
POST   /api/auth/login               Verifica credenciales          200 / 400 / 401

------------------------------------------------------------
CATEGORIAS
------------------------------------------------------------
GET    /api/categorias[?tipo=GASTO|INGRESO]   Lista               200
GET    /api/categorias/{id}                   Consulta             200 / 404
POST   /api/categorias                        Crea                 201 / 400
PUT    /api/categorias/{id}                   Actualiza            200 / 400 / 404
DELETE /api/categorias/{id}                   Elimina              204 / 400 / 404

# PROMPT MAESTRO DE DESARROLLO - MI FINANZAPP

## OBJETIVO GENERAL

Desarrollar una aplicación web responsive llamada "Mi FinanzApp" para la gestión de finanzas personales.

La aplicación permitirá:

* Registro e inicio de sesión de usuarios.
* Gestión de ingresos.
* Gestión de gastos.
* Gestión de categorías personalizadas.
* Gestión de presupuestos mensuales.
* Dashboard financiero.
* Historial de movimientos.
* Reportes y análisis.
* Recordatorios financieros.
* Contenido educativo.

El sistema debe desarrollarse utilizando Java Spring Boot, PostgreSQL (Supabase), Thymeleaf y Bootstrap.

La arquitectura debe seguir buenas prácticas de desarrollo empresarial utilizando capas Controller, Service, Repository y Entity.

# CONFIGURACIÓN DE VARIABLES DE ENTORNO

NO almacenar credenciales directamente en application.properties.

Utilizar variables de entorno.

application.properties:

spring.datasource.url=${DB_URL}
spring.datasource.username=${DB_USER}
spring.datasource.password=${DB_PASSWORD}

spring.jpa.hibernate.ddl-auto=update

Crear archivo .env.example:

DB_URL=
DB_USER=
DB_PASSWORD=

---

# CONFIGURACIÓN DE SUPABASE

La aplicación debe conectarse automáticamente a PostgreSQL de Supabase.

El proyecto debe ser capaz de:

1. Detectar la conexión.
2. Crear automáticamente las tablas mediante Hibernate.
3. Actualizar el esquema si existen nuevas entidades.

No se deben crear tablas manualmente.

Las entidades Java serán responsables de generar toda la estructura de la base de datos.
